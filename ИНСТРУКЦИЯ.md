# OMG — Oh My Gantt
## Инструкция по запуску

---

## Шаг 1 — Установить Node.js

1. Открой браузер и перейди на сайт: **https://nodejs.org/ru**
2. Нажми большую зелёную кнопку **«Рекомендуется для большинства»** (LTS версия)
3. Скачай установщик и запусти его
4. Нажимай **Next / Далее** на всех шагах, ничего не меняй
5. После установки нажми **Finish**

**Проверка:** Открой терминал (см. Шаг 2) и введи:
```
node --version
```
Должно появиться что-то вроде `v20.11.0` — значит всё готово.

---

## Шаг 2 — Открыть терминал

**На Windows:**
- Нажми `Win + R`, введи `cmd`, нажми Enter
- Или найди в меню Пуск приложение **«Командная строка»**

**На Mac:**
- Нажми `Cmd + Пробел`, введи `Terminal`, нажми Enter

---

## Шаг 3 — Создать папку проекта

Скопируй папку `omg` из архива в удобное место на компьютере.
Например: `C:\Projects\omg` (Windows) или `~/Projects/omg` (Mac)

---

## Шаг 4 — Перейти в папку проекта

В терминале введи команду (замени путь на свой):

**Windows:**
```
cd C:\Projects\omg
```

**Mac:**
```
cd ~/Projects/omg
```

---

## Шаг 5 — Установить зависимости

В терминале введи:
```
npm install
```

Подожди 1–3 минуты. Будут скачиваться пакеты — это нормально.
В конце должна появиться надпись вида `added 1500 packages`.

---

## Шаг 6 — Запустить приложение

Введи:
```
npm start
```

Через несколько секунд автоматически откроется браузер на адресе:
**http://localhost:3000**

Это и есть твоё приложение OMG! 🎉

---

## Как использовать каждый день

После первого запуска тебе нужно делать только **Шаги 4 и 6**:

1. Открыть терминал
2. Перейти в папку: `cd C:\Projects\omg`
3. Запустить: `npm start`

---

## Данные сохраняются автоматически

Все изменения (задачи, инженеры, прогресс) сохраняются в браузере (localStorage).
Данные сохраняются между сессиями на одном компьютере и браузере.

> ⚠️ Если очистить данные браузера — данные сбросятся на начальные. Чтобы этого избежать, не нажимай «Очистить данные сайтов» в настройках браузера для localhost.

---

## Как остановить приложение

В терминале нажми `Ctrl + C` и подтверди (`y + Enter`).

---

## Если что-то пошло не так

**Ошибка `npm: command not found`**
→ Node.js не установлен или нужно перезапустить терминал после установки.

**Ошибка `Cannot find module`**
→ Повтори `npm install` в папке проекта.

**Браузер не открылся автоматически**
→ Открой вручную: http://localhost:3000

**Порт 3000 занят**
→ npm спросит использовать другой порт, нажми `Y`.
