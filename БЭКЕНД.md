# OMG v0.8 — Бэкенд на JSON-файле
## Инструкция по установке

---

## Что изменилось

Данные теперь хранятся в файле **server/data.json** на твоём компьютере.
Никаких баз данных и компиляции — только Node.js, который уже установлен.

---

## Шаг 1 — Замени файлы проекта

Скопируй содержимое архива `omg_v08.zip` в папку `C:\Projects\OMG` с заменой.

Структура после замены:
```
C:\Projects\OMG\
├── src\              ← фронтенд (React)
├── server\           ← бэкенд (новая папка!)
│   ├── index.js
│   ├── db.js
│   └── package.json
├── public\
└── package.json      ← обновлён
```

---

## Шаг 2 — Установи зависимости бэкенда

```
cd C:\Projects\OMG\server
npm install
```

Устанавливает только `express` и `cors` — быстро, без компиляции.

---

## Шаг 3 — Установи зависимости фронтенда

```
cd C:\Projects\OMG
npm install
```

---

## Шаг 4 — Запусти

```
cd C:\Projects\OMG
npm start
```

Запускается сервер на порту 3001 и React на порту 3000.
При первом запуске автоматически создаётся `server/data.json` с тестовыми данными.

---

## Где хранятся данные

```
C:\Projects\OMG\server\data.json
```

Обычный JSON-файл — можно открыть в Блокноте, скопировать как бэкап,
перенести на другой компьютер.

---

## Кнопка «Сбросить тестовые данные»

В нижней части сайдбара — 🔄 Сбросить тестовые данные.
Перезаписывает `data.json` тестовым набором. Просит подтверждение.

Тестовые данные хранятся в `server/db.js` в константе `SEED_DATA`.
Чтобы изменить тестовый набор — отредактируй её и нажми кнопку сброса.

---

## Обновление в будущем

При получении новой версии:
1. Замени папку `src` и файлы `server/index.js`, `server/db.js`
2. **Не трогай** `server/data.json` — это твои данные
3. **Не трогай** `node_modules`
4. Запусти `npm start`
